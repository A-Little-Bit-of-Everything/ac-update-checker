# Patch notes — Andromeda's Create v0.3.2 · Patch 1

### "Rails & Rollin' Stock" — Patch 1

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v032-patch1.zip) · [Modrinth](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v032-patch1.mrpack) · [CurseForge](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v032-patch1%20CF.zip) · [Server Pack](https://www.andromedacat.net/cdn/Andromeda's%20Create%20Server%20v032-patch1.zip)

**Server:** ready-to-run NeoForge server, requires Java 21. **8 GB RAM or higher is recommended** in the launch arguments.

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

A small patch on top of **v0.3.2 "Rails & Rollin' Stock"**. **6 mods** were updated. No mods were added or removed. This is a drop-in update — install over v0.3.2 (or download a fresh v0.3.2 Patch 1 pack).

Updated because a tester found a bug with Sophisticated Backpacks where if you had Pump Upgrades installed, the server or client singleplayer server would crash. Luckily Sophisticated Backpacks and Sophisticated Core had an update.

<sub>Thank you TruBlueFox2</sub>

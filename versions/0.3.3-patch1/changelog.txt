**Server:** ready-to-run NeoForge server, requires Java 21. **8 GB RAM or higher is recommended** in the launch arguments.

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.265

A targeted maintenance patch on top of **v0.3.3**. Updates **DyeDepotCompat** to `0.2.2`.

### Updated

- **[DyeDepotCompat](https://www.andromedacat.net/dyedepotcompat/)** `0.2.1` &rarr; `0.2.2` &mdash; unified compatibility bridge for Dye Depot, adding bug fixes and recipe/tag adjustments for modded dye interactions across Music Disc Maker and Arts & Crafts.

### Server Changes

- **Server Pack updated** to include `dyedepotcompat-0.2.2.jar` (replacing `dyedepotcompat-0.2.1.jar`).

### Removed

- `dyedepotcompat-0.2.1.jar` (superseded by `0.2.2`).

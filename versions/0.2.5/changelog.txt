# Changelog — Andromeda's Create

## v0.2.5

### "Gear & Graves"

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v025.zip) · [Modrinth](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v025.mrpack) · [CurseForge](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v025%20CF.zip)

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

**8 new mods** were added. No mods were updated or removed.

### Added

- **[Curios API](https://modrinth.com/mod/curios)** `9.5.1` — accessory/equipment slot API used by many other mods.
- **[BaguetteLib](https://modrinth.com/mod/baguettelib)** `2.0.7` — shared library dependency.
- **[Lootr](https://modrinth.com/mod/lootr)** `1.11.38.127` — per-player loot containers so everyone gets their own loot.
- **[GraveStone Mod](https://modrinth.com/mod/gravestone-mod)** `1.0.40` — drops your items into a recoverable grave on death.
- **[Gravestone x Curios API Compat](https://modrinth.com/mod/gravestone-x-curios-api-compat)** `4.2.0` — makes GraveStone save Curios slot items too.
- **[Create Stuff 'N Additions](https://modrinth.com/mod/create-stuff-additions)** `2.1.4b` — adds jetpacks, backtanks, and other Create gadgets.
- **[Create: Stuff 'N Additions - Tank Fix](https://modrinth.com/mod/create-stuff-and-addition-tank-fix)** `1.3` — compatibility/bug-fix patch for Stuff 'N Additions (spout, Curios, upgrades).
- **[Create: Curios Jetpack & Backtank](https://modrinth.com/mod/create-curios-jetpack)** `1.2.0` — lets Create jetpacks and backtanks be worn in Curios slots.

### Updated

- None.

### Removed

- None.

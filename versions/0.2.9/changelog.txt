# Changelog — Andromeda's Create

## v0.2.9

### "Factories & Frontiers"

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v029.zip) · [Modrinth](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v029.mrpack) · [CurseForge](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v029%20CF.zip) · [Server Pack](https://www.andromedacat.net/cdn/Andromeda's%20Create%20Server%20v029.zip)

**Server:** ready-to-run NeoForge server, requires Java 21. **8 GB RAM or higher is recommended** in the launch arguments.

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

**15 new mods** were added. No mods were updated or removed. This drop is split between a large **structures** expansion (Create-themed and vanilla-style) and a new **industry & pollution** line built around Create: TFMG.

### Added

**Create structures**

- **[Create: Easy Structures](https://modrinth.com/mod/create-easy-structures)** `0.2a` — worldgen structures built with Create blocks.
- **[Create: Rustic Structures](https://modrinth.com/mod/create-rustic-structures)** `1.0.1` — functional and decorative structures using Create blocks.
- **[Create: Structures Arise](https://modrinth.com/mod/create-structures-arise)** `176.49.49` — adds 28 new Create-themed structures to worldgen.
- **[Create Aeronautics Structures](https://modrinth.com/mod/aeronautics-structures)** `1.2` — structures for Create Aeronautics.

**Vanilla-style structures**

- **[Structures](https://modrinth.com/mod/structures-mod)** `4.4` — an extensive set of new worldgen structures.
- **[Moog's Voyager Structures](https://modrinth.com/mod/moogs-voyager-structures)** `5.1.3` — 130+ vanilla-style structures with dungeons and enemies.
- **[MES — Moog's End Structures](https://modrinth.com/mod/mes-moogs-end-structures)** `2.1.1` — vanilla-style structures for the End dimension.
- **[Moog's Structure Lib](https://modrinth.com/mod/moogs-structure-lib)** `3.4.2` — shared library for the Moog's structure mods.

**Industry & pollution**

- **[Create: TFMG Community Edition](https://modrinth.com/mod/tfmg-community-edition)** `1.3.2a` — heavy engineering and oil for Create (a community-maintained fork of [Create: The Factory Must Grow](https://modrinth.com/mod/create-tfmg)).
- **[Create: Smog](https://modrinth.com/mod/create-smog)** `0.4.1` — adds pollution to Create, compatible with Pollution of the Realms. *(ships disabled by default)*
- **[Pollution of the Realms](https://modrinth.com/mod/pollution-of-the-realms)** `9.1.12.0` — environmental pollution mechanics with real consequences for the world. *(ships disabled by default)*
- **[Advanced Chimneys](https://modrinth.com/mod/advanced-chimneys)** `11.1.13.0` — chimney pipes that route smoke from any heat source outdoors.
- **[Large Ore Deposits](https://modrinth.com/mod/large-ore-deposits)** `9.1.7.0` — rare, supermassive ore deposits that make mining worthwhile.

**Libraries & frameworks** *(dependencies for the above)*

- **[ForgeEndertech](https://modrinth.com/mod/forgeendertech)** `12.1.4.0` — core library powering the Endertech mods (Chimneys, Pollution, Large Ore Deposits).

**Rendering**

- **[Distant Horizons](https://modrinth.com/mod/distanthorizons)** `3.3.3` — massively increases render distance with a level-of-detail system.

### Updated

- None.

### Removed

- None.

> **Note:** A few mods ship with this pack **disabled by default** (`.disabled`) — enable them manually in your `mods` folder if you want them:
> - *Distant Horizons* `3.3.3` — massively increased render distance.
> - *Create: Smog* `0.4.1` and *Pollution of the Realms* `9.1.12.0` — the pollution layer; disabled by default so pollution is opt-in.
> - *Ambush* `1.1.6`.

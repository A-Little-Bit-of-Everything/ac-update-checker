# Changelog — Andromeda's Create

## v0.2.2

### "Maps & Movement"

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v022.zip)

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

**10 new mods** were added. No mods were updated or removed. This update is all
about exploration, navigation, and getting around.

### Added

- **[Antique Atlas](https://modrinth.com/mod/antique-atlas-neoforge)** `3.1.2` — a scrollable, auto-filling map in book form.
- **[Antique Transport](https://modrinth.com/mod/antique-transport)** `1.3.0` — early-game transport additions.
- **[Surveyor Map Framework](https://modrinth.com/mod/surveyor)** `1.1.2` — the mapping/exploration framework behind the map tools.
- **[HT's TreeChop](https://modrinth.com/mod/treechop)** `0.19.3` — fell whole trees by chopping once.
- **[Sable Tree Chopper](https://modrinth.com/mod/dragged-tree-chopper)** `1.0.4` — alternative tree-felling helper.
- **[Presence Footsteps](https://modrinth.com/mod/presence-footsteps)** `1.12.0-beta.1` — context-aware footstep sounds.
- **[Presence Footsteps x Sable](https://modrinth.com/mod/pfsable)** `1.0` — Sable compatibility for Presence Footsteps.
- **[Barebones McQoy](https://modrinth.com/mod/mcqoy)** `0.4.1` — lightweight quality-of-life tweaks.
- **[owo-lib](https://modrinth.com/mod/owo-lib)** `0.12.15.6-beta.1` — shared library dependency.
- **[YetAnotherConfigLib (YACL)](https://modrinth.com/mod/yacl)** `3.7.0` — in-game config screen library used by other mods.

### Updated

- None.

### Removed

- None.

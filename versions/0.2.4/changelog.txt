# Changelog — Andromeda's Create

## v0.2.4

### "Backpacks & Beyond"

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create%20v024.zip) · [Modrinth](https://www.andromedacat.net/cdn/Andromeda's%20Create%20024.mrpack) · [CurseForge](https://www.andromedacat.net/cdn/Andromeda's%20Create%20024%20CF.zip)

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

**10 new mods** were added and **1 mod** was removed. No mods were updated.

### Added

- **[Sophisticated Core](https://modrinth.com/mod/sophisticated-core)** `1.5.13.2404` — shared library for the Sophisticated mods.
- **[Sophisticated Backpacks](https://modrinth.com/mod/sophisticated-backpacks)** `3.26.12.2208` — highly upgradeable backpacks with storage, tools, and automation.
- **[Sophisticated Backpacks Create Integration](https://modrinth.com/mod/sophisticated-backpacks-create-integration)** `0.2.3.194` — lets Sophisticated Backpacks work with Create contraptions.
- **[Sophisticated Storage](https://modrinth.com/mod/sophisticated-storage)** `1.6.7.2184` — upgradeable storage barrels and chests.
- **[Sophisticated Storage Create Integration](https://modrinth.com/mod/sophisticated-storage-create-integration)** `0.1.23.246` — Create compatibility for Sophisticated Storage.
- **[Incendium](https://modrinth.com/mod/incendium)** `5.4.4` — overhauled Nether with new biomes, structures, and bosses.
- **[Nullscape](https://modrinth.com/mod/nullscape)** `1.2.14` — reworks the End into a lonely, atmospheric dimension.
- **[Structory](https://modrinth.com/mod/structory)** `1.3.7` — adds atmospheric, lightweight structures across the world.
- **[Create Aeronautics Discovery](https://modrinth.com/mod/create-aeronautics-discovery)** `2.2.0` — aeronautics content/discovery addon for Create.
- **[Create: Disc Maker](https://modrinth.com/mod/create-disc-maker)** `0.1.0` — craft custom music discs with Create.

### Updated

- None.

### Removed

- **Tree Physics** — removed from the pack (no longer on Modrinth or CurseForge in this build).

# Changelog — Andromeda's Create

## v0.2.0

### "Genesis"

**Download:** [Prism/MC Launcher](https://www.andromedacat.net/cdn/Andromeda's%20Create.zip)

**Minecraft:** 1.21.1 · **NeoForge:** 21.1.262

The earliest recovered build of Andromeda's Create — the original **82-mod**
foundation that every later version builds on. Previously thought lost; now
archived. It is already a full Create-focused pack built around automation,
power generation, cannons, and aeronautics.

### Highlights of the baseline roster

- **[Create](https://modrinth.com/mod/create)** `6.0.10` — the core automation and contraption mod the whole pack is built around.
- **[Create Big Cannons](https://modrinth.com/mod/create-big-cannons)** `5.11.7` — buildable, fireable cannons.
- **[Create Aeronautics](https://modrinth.com/mod/create-aeronautics)** `1.3.2` — airships and aerial contraptions.
- **[Create: Power Grid](https://modrinth.com/mod/create-power-grid)** `0.6.2`, **Power Components** `1.3.0`, **Power Chip** `2.1.2`, **Create: Stats & Power** `1.15.0` — the electrical/power-network suite.
- **[Create Diesel Generators](https://modrinth.com/mod/create-diesel-generators)** `1.3.15`, **[Create: Steam Powered](https://modrinth.com/mod/create-steam-powered)** `3.2.1`, **[Create: Solar Powered](https://modrinth.com/mod/create-solar-powered)** `1.2.7` — alternative power sources.
- **[Create Crafts & Additions](https://modrinth.com/mod/create-crafts-additions)** `1.7.2`, **[Create: Connected](https://modrinth.com/mod/create-connected)** `1.3.3`, **[Create: Copycats+](https://modrinth.com/mod/copycats)** `3.0.9`, **[Create Deco](https://modrinth.com/mod/createdeco)** `2.1.3`, **[Create: Framed](https://modrinth.com/mod/create-framed)** `1.8.2`, **[Create: Interiors](https://modrinth.com/mod/create-interiors)** `0.6.1` — building and decoration add-ons.
- **[Create: Airwaves](https://www.andromedacat.net/cdn/airwaves-1.21.1-0.1.0.jar)** `0.1.0` — bundled at this stage as a direct jar.

…plus the full supporting cast of ~82 mods (libraries, QoL, and more Create addons).
